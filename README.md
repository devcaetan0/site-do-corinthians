# 🖤 Corinthians - Portal Estático 🤍

Este é um projeto de site estático desenvolvido para reunir notícias, novidades fictícias e a escalação do Sport Club Corinthians Paulista. O projeto conta com uma estrutura bem definida em HTML5 e estilização personalizada em CSS3 utilizando a identidade visual do clube.

---

### 🚀 Funcionalidades

* **Feed de Notícias:** Seção interativa com cards estilizados apresentando manchetes, imagens e resumos das últimas notícias do Timão.
* **Escalação Principal (2026):** Galeria visual com os cards dos jogadores titulares (incluindo Hugo Souza, Rodrigo Garro, Memphis Depay, Yuri Alberto, entre outros).
* **Barra de Navegação:** Cabeçalho em estilo alvinegro com o escudo oficial do clube.
* **Animação Flutuante:** Elemento visual (GIF) fixado no canto inferior da página para reforçar a temática do clube.
* **Design Responsivo com Flexbox:** Organização adaptável dos cards de notícias e da escalação através de propriedades modernas do CSS3.

---

### 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo (`<header>`, `<nav>`, `<main>`, `<section>`).
* **CSS3:** Estilização personalizada, utilização do modelo Flexbox para alinhamento, bordas temáticas e posicionamento fixo (`position: fixed`).
